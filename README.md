# Basic Calculator (C++)

A beginner-friendly **C++ basic calculator** project to help you start your programming journey.

## Features
- Addition
- Subtraction
- Multiplication
- Division

## Getting Started
1. Save your calculator code in a file (for example: `calculator.cpp`).
2. Compile using g++:
   ```bash
   g++ calculator.cpp -o calculator
   ```
3. Run:
   ```bash
   ./calculator
   ```

## Goal
This project is a simple foundation for learning:
- C++ syntax
- User input and output
- Conditional logic
- Basic arithmetic operations
